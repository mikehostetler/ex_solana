# Contributing to Karo

Thank you for your interest in contributing to Karo!

## Development Setup

1. Clone the repository
2. Install dependencies: `mix deps.get`
3. Set up git hooks: `mix setup`
4. Run tests: `mix test`
5. Run quality checks: `mix quality`

## Code Style

- Run `mix format` before committing
- All code must pass `mix quality`
- Follow existing patterns in the codebase
- Add tests for new functionality

## Commit Messages

Use [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` - New features
- `fix:` - Bug fixes
- `docs:` - Documentation changes
- `test:` - Test changes
- `chore:` - Maintenance tasks
- `refactor:` - Code refactoring

## Pull Requests

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run `mix quality` and `mix test`
5. Submit a pull request

## Questions?

Open an issue or reach out on [Discord](https://agentjido.xyz/discord).
