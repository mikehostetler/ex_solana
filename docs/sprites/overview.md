# Sprites Overview

Sprites are programmable Linux execution environments from Fly.io. Each Sprite is an isolated container you can create, configure, run code in, and destroy programmatically.

## Core Concepts

### What is a Sprite?

A Sprite is a persistent Linux container that:

- Executes arbitrary code securely
- Persists filesystem state between hibernations
- Has a unique HTTPS URL for HTTP access
- Auto-hibernates when idle (no compute charges)
- Wakes instantly on demand

### Use Cases

- Execute code generated by language models
- Create isolated environments for untrusted code
- Clone git repos and run test suites or linters
- Run containers with arbitrary dependencies

## Basic Workflow

```elixir
# 1. Create a client
client = Sprites.new(System.get_env("SPRITE_TOKEN"))

# 2. Create a sprite
{:ok, sprite} = Sprites.create(client, "my-sprite")

# 3. Execute commands
{output, 0} = Sprites.cmd(sprite, "python", ["-c", "print('hello')"])

# 4. Stream long-running commands
sprite
|> Sprites.stream("bash", ["-c", "for i in {1..10}; do date; sleep 1; done"])
|> Stream.each(&IO.write/1)
|> Stream.run()

# 5. Clean up
:ok = Sprites.destroy(sprite)
```

## Key Features

### Automatic Hibernation

- Sprites hibernate after **30 seconds** of inactivity
- No compute charges while hibernated
- Full state preserved on disk
- Instant wake on next request

### HTTP Access

Every Sprite has a unique URL:
```
https://my-sprite-abc123.sprites.app
```

### Checkpoints

Save and restore Sprite state:
```elixir
{:ok, _} = Sprites.create_checkpoint(sprite, comment: "before deploy")
{:ok, _} = Sprites.restore_checkpoint(sprite, "v1")
```

### Detachable Sessions

Run processes that persist after disconnecting:
```elixir
{:ok, cmd} = Sprites.spawn(sprite, "npm", ["run", "dev"], detachable: true)
```

## Activity Detection

A Sprite is considered active when:

1. A command is executing
2. stdin is being written to
3. An active TCP connection exists to its URL
4. A detachable session is running

Otherwise, it hibernates after 30 seconds.
